# 🔔 Звоночек 3.0

[![CI](https://github.com/qwkejkqwje1/Zvonochek2/actions/workflows/ci.yml/badge.svg)](https://github.com/qwkejkqwje1/Zvonochek2/actions/workflows/ci.yml)
[![Release](https://img.shields.io/github/v/release/qwkejkqwje1/Zvonochek2)](https://github.com/qwkejkqwje1/Zvonochek2/releases/latest)

Звонки, видео, чат и файлы **напрямую между компьютерами** — без серверов, аккаунтов и регистрации.
Один файл `zvonochek.exe` для Windows 10/11, ничего устанавливать не нужно.

- 📞 **Аудио- и видеозвонки** (WebRTC), демонстрация экрана, выбор микрофона/камеры/динамиков, шумоподавление.
- 🌉 **Аудиомост**: если прямое WebRTC-соединение не пробивается (строгий NAT, CGNAT, VPN), голос сам переходит в зашифрованный канал Звоночка (Opus).
- 💬 **Чат**: статусы «доставлено/прочитано», «печатает…», офлайн-очередь — сообщение уйдёт, когда собеседник появится в сети.
- 📁 **Файлы** до 8 ГБ (лимит настраивается): подтверждение приёма, проверка целостности SHA-256, предпросмотр и автоприём картинок.
- 🔎 **Поиск собеседников**: локальная сеть (mDNS), VirtualBox хост↔гость (маяк), интернет (DHT, hole punching, relay).
- 🔐 **Безопасность**: только подтверждённые контакты, сквозное шифрование, код безопасности для сверки, блокировка.
- 🖥️ **Десктоп**: отдельное окно, значок в трее, автозапуск с Windows, уведомления, тёмная/светлая тема, несколько профилей.

## Установка и первый запуск

1. Скачайте `zvonochek.exe` со страницы [Releases](https://github.com/qwkejkqwje1/Zvonochek2/releases/latest) и запустите.
2. **SmartScreen** («Система Windows защитила ваш компьютер») появляется, потому что exe не подписан платным сертификатом:
   нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. **Брандмауэр Windows** спросит доступ к сети — разрешите хотя бы для **частных сетей**
   (без этого вас не найдут в локальной сети и входящие соединения будут хуже работать).
4. Откроется окно Звоночка. Закрытие окна сворачивает программу в трей — звонки и сообщения продолжают приходить.
   Полный выход — правой кнопкой по значку в трее → «Выход».

Если антивирус ругается на exe — это типичное ложное срабатывание на неподписанные Go-программы: проверьте
сумму из `SHA256SUMS` или соберите exe сами из исходников (см. ниже).

Окно открывается через Microsoft Edge (есть в любой Windows 10/11) или Chrome в режиме приложения с отдельным профилем:
без вкладок и адресной строки, разрешения на микрофон и камеру запоминаются.

## Как добавить собеседника

| Способ | Что делать | Подтверждение |
|---|---|---|
| **Код приглашения** (рекомендуется) | «Добавить» → «Мой код» → скопировать `zv3:…` и отправить собеседнику любым способом. Он вставляет его во «Ввести код собеседника». | не нужно — вы сразу контакты |
| **Рядом** (та же Wi-Fi/LAN или VirtualBox) | Собеседник появляется в списке «Рядом» → «Добавить». | собеседник принимает запрос |
| **По ID** | Вставить ID собеседника вместо кода. | собеседник принимает запрос |

Код действует 7 дней и подходит для нескольких человек. Кнопка «Новый код» отменяет старый.
Код содержит ваш ID и актуальные адреса, поэтому по нему соединение находится быстрее всего.

Чтобы исключить подмену, сравните **код безопасности** (карточка контакта → «Сверить код безопасности») голосом или лично —
у обоих он должен совпадать.

## Сеть

| Порт | Назначение |
|---|---|
| `127.0.0.1:47320` TCP | интерфейс программы (доступен только с этого компьютера) |
| `47321` TCP + UDP (QUIC) | P2P-соединения (меняется в «Настройки → Сеть → P2P-порт») |
| `47329` TCP | маяк для виртуальных машин |

Как Звоночек ищет собеседника — параллельно, кто первый:
1. **Адреса из кода приглашения** и последние известные адреса контакта.
2. **Локальная сеть** — mDNS.
3. **Интернет** — публичная сеть libp2p (DHT), пробитие NAT (hole punching, UPnP), публичные и **свои** relay-серверы.

Если звонок не соединяется напрямую, примерно через 15 секунд он автоматически переводится на аудиомост (видео в этом режиме недоступно).

### VirtualBox: хост ↔ гостевая ОС

- **NAT (по умолчанию)** — работает само: гостевая система спрашивает маяк хоста по адресу `10.0.2.2:47329` и подключается к нему;
  ответные сообщения и звонки идут по этому же соединению. Нужно лишь, чтобы Звоночек был запущен в обеих системах.
- **Виртуальный адаптер хоста (Host-only)** — маяк `192.168.56.1` + mDNS. Разрешите Звоночек в брандмауэре на обеих системах.
- **Сетевой мост (Bridged)** — как обычная локальная сеть.

Собеседник из списка «Рядом» **не становится контактом автоматически** — нужно добавить его и подтвердить запрос.

### Свой relay-сервер (если у обоих строгий NAT)

Мобильный интернет и CGNAT иногда не дают соединиться напрямую. Тогда поможет свой relay на любом VPS
с публичным IP (подойдут бесплатные тарифы, например Oracle Cloud Always Free):

```bash
chmod +x zvonochek-relay-linux-amd64
./zvonochek-relay-linux-amd64 -port 4002            # -announce <IP>, если VPS не видит свой публичный адрес
```

Relay выведет адрес вида `/ip4/203.0.113.10/tcp/4002/p2p/12D3KooW…` — добавьте его в
**«Настройки → Сеть → Свои relay-серверы»** и откройте порт 4002 TCP и UDP в панели VPS.
Контакты получат адрес вашего relay автоматически при добавлении. Трафик через relay остаётся зашифрованным
сквозным шифрованием — сервер его не видит. Ограничить доступ можно списком ID: `-allow allowed.txt`.

<details>
<summary>systemd-сервис</summary>

```ini
# /etc/systemd/system/zvonochek-relay.service
[Unit]
Description=Zvonochek relay
After=network-online.target
Wants=network-online.target

[Service]
ExecStart=/opt/zvonochek/zvonochek-relay-linux-amd64 -port 4002 -key /opt/zvonochek/relay_identity.key
Restart=always
DynamicUser=yes
StateDirectory=zvonochek

[Install]
WantedBy=multi-user.target
```

Ключ `relay_identity.key` определяет адрес relay — не удаляйте его, иначе адрес изменится.
При `DynamicUser=yes` укажите путь ключа внутри `StateDirectory`: `-key /var/lib/zvonochek/relay_identity.key`.
</details>

Для видео в очень строгих сетях можно указать свой TURN-сервер (например, coturn) в «Настройки → Сеть → Звонки (WebRTC)».

## Безопасность

- **Шифрование.** Все соединения libp2p шифруются (Noise / TLS 1.3), личность узла — ключ Ed25519, ID — хеш открытого ключа,
  подделать его нельзя. Звонки WebRTC дополнительно защищены DTLS-SRTP. Relay и STUN-серверы содержимое не видят.
- **Только контакты.** Сообщения, звонки и файлы принимаются только от подтверждённых контактов.
  Незнакомцы могут лишь отправить запрос на добавление (с ограничением частоты). Заблокированные не могут ничего.
- **Локальный интерфейс** слушает только `127.0.0.1`. Вход — по одноразовому токену, который превращается в cookie
  `HttpOnly; SameSite=Strict`; проверяются заголовок `Host` (защита от DNS rebinding), `Origin` и CSRF-заголовок;
  строгая политика CSP. Другие сайты в браузере не могут управлять Звоночком.
- **Протокол.** Все кадры ограничены по размеру (256 КБ управляющие, 4 КБ голосовые), текст и имена обрезаются,
  поток от каждого узла ограничен по частоте.
- **Файлы** принимаются только после подтверждения (или автоприём картинок, если включён), пишутся во временный `.part`,
  сверяются по SHA-256 и только потом переименовываются; существующие файлы не перезаписываются, имена очищаются
  от опасных символов. На Windows файлу ставится «метка из интернета», поэтому SmartScreen предупредит при запуске
  полученного exe.

## Данные

Профиль хранится в `%APPDATA%\Zvonochek2\profiles\<профиль>` (по умолчанию `default`):

| Файл/папка | Что это |
|---|---|
| `identity.key` | ключ вашей личности — **это и есть ваш аккаунт**, не передавайте его никому |
| `settings.json`, `contacts.json`, `history\` | настройки, контакты, переписка |
| `logs\zvonochek.log` | журнал (пригодится при проблемах со связью) |
| `window\` | профиль окна (размер, разрешения микрофона и камеры) |

Полученные файлы сохраняются в `Загрузки\Zvonochek` (меняется в настройках).
Перенос на другой компьютер — скопируйте папку профиля целиком. Повреждённый файл настроек или истории не мешает
запуску: он сохраняется рядом как `*.broken-<время>`, а программа стартует с остальными данными.

Звоночек 2.x будет найден автоматически: ключ личности переносится, ID не меняется.

### Параметры командной строки

```text
zvonochek.exe [-profile имя] [-data-dir папка] [-port 47320] [-p2p-port 47321]
              [-relay /ip4/…/p2p/…] [-background] [-no-internet] [-no-lan] [-version]
```

`-profile work` — второй независимый аккаунт на том же ПК (например, чтобы позвонить самому себе для проверки).
`-background` — запуск в трей без окна (так работает автозапуск).

## Сборка из исходников

Нужен [Go 1.26+](https://go.dev/dl/). Внешних зависимостей (C-компилятор, Node.js) нет.

```bat
build_windows.bat          :: тесты + dist\zvonochek.exe и dist\zvonochek-relay.exe
build_windows.bat fast     :: без тестов
```

```bash
./build.sh                 # тесты + все платформы в ./dist (Windows x64/ARM64, Linux, relay) + SHA256SUMS
go test -race ./...        # тесты с детектором гонок
```

Иконка и сведения о версии exe лежат в `cmd/zvonochek/rsrc_windows_*.syso` (генерируются
[go-winres](https://github.com/tc-hib/go-winres) из `cmd/zvonochek/winres/winres.json`).

**Выпуск релиза:** `git tag v3.0.0 && git push origin v3.0.0` — GitHub Actions прогонит тесты на Linux и Windows,
соберёт все файлы и опубликует релиз с примечаниями из `CHANGELOG.md`.

### Устройство

```text
cmd/zvonochek          программа: окно, трей, автозапуск, один экземпляр на профиль
cmd/zvonochek-relay    необязательный relay-сервер (Circuit Relay v2)
internal/node          P2P-ядро на go-libp2p: контакты, приглашения, чат, файлы, сигналинг звонков, аудиомост, поиск
internal/store         хранилище: атомарная запись, устойчивость к повреждённым файлам
internal/api           локальный HTTP/WebSocket API с защитой сессии
internal/desktop       окно приложения, трей, уведомления, системные функции Windows
web/static             интерфейс (чистый JS без сборки): чат, звонки WebRTC, настройки
```

Протоколы libp2p: `/zvonochek/3/control` (управление и чат), `/zvonochek/3/file` (файлы), `/zvonochek/3/voice` (аудиомост).
С версиями 2.x по сети Звоночек 3 несовместим — обновите программу у обоих собеседников.
