# 🔔 Звоночек 2.1 (Zvonochek 2.1)

Десктопный P2P-клиент для защищенных аудиозвонков, чата и обмена файлами (Go + go-libp2p + WebRTC + Go Audio Bridge).

---

## 🔍 Почему в первой версии не удалось соединиться (и что исправлено в 2.1)

1. **Ошибка пути `//go:embed ../../web/index.html`:**
   Стандарт компилятора Go запрещает подъем в родительские директории (`..`) внутри `//go:embed`. Теперь встроенные ресурсы вынесены в отдельный пакет `web/embed.go` (`//go:embed index.html`), что гарантирует чистую сборку на любой ОС.
2. **Подстановка `127.0.0.1` в Multiaddr:**
   В v2.0 в интерфейс выводился первый адрес из списка (`data.listen_addrs[0]`), которым почти всегда оказывается локальный `/ip4/127.0.0.1/...`. При отправке такого адреса собеседнику его клиент пытался позвонить сам себе.
   - **Исправление в 2.1:** Создана система **приглашений `zv2://...`** (`internal/p2p/identity.go`), которая автоматически отфильтровывает `127.0.0.1`, подключается к публичным узлам Bootstrap для определения вашего внешнего IP через протокол `Identify`, собирает все внешние, Relay (`/p2p-circuit`) и LAN-маршруты в единый код с одноразовым секретом.
   - Для компьютеров в одной Wi-Fi/LAN сети добавлен автоматический поиск **mDNS** (`internal/p2p/mdns.go`) — узлы видят друг друга без копирования адресов.
3. **Разрыв между маршрутом сигналинга (libp2p) и голоса (WebRTC) + гонки SDP:**
   - **Исправление в 2.1:**
     - Внедрен строгий автомат состояний звонка (`call_id`, `attempt_id`, `seq`), последовательная очередь `signalingChain` и буферизация ICE-кандидатов (`pendingCandidates`) до завершения `setRemoteDescription`.
     - В настройках можно указать собственный **TURN-сервер**.
     - **Главное — добавлен Go libp2p Audio Bridge (`/zvonochek/voice/2.1.0`):** если прямой WebRTC/STUN заблокирован провайдером или корпоративным файрволом, голос за 8 секунд автоматически переключается на передачу аудиофреймов напрямую через Go-демон и активный туннель libp2p (включая работу через Circuit Relay v2) с кольцевым буфером, сбрасывающим устаревшие пакеты для предотвращения накопления задержки.

## 📊 Три раздельных индикатора состояния

В верхней панели интерфейса теперь отображаются три независимых статуса:
1. **1. Обнаружение и контакт:** Показывает, найден ли пир (через mDNS или приглашение), его никнейм и 6-значный **Код сверки безопасности** (Safety Code на основе SHA-256 обоих Peer ID).
2. **2. Служебный канал (libp2p):** Показывает реальный маршрут (`Прямой QUIC/TCP` или `Через Circuit Relay`) и текущий пинг (`RTT мс`).
3. **3. Голосовой канал (Аудио):** Показывает, как именно идет звук: `Прямой WebRTC P2P`, `WebRTC TURN Relay` или `Go libp2p Audio Bridge`, плюс живую телеметрию `getStats()` (битрейт, джиттер, потери пакетов).

## 🚀 Сборка и запуск на Windows

1. Распакуйте архив и запустите `build_windows.bat`.
   Скрипт соберет два файла:
   - `zvonochek.exe` — основное приложение пользователя.
   - `zvonochek-relay.exe` — выделенный сервер-ретранслятор Circuit Relay v2 (если вы захотите поднять свой собственный релей на дешевом VPS).
2. Запустите `zvonochek.exe`.
   - При первом запуске создается файл `identity.key`, сохраняющий ваш постоянный `Peer ID`.
   - Браузер откроется по ссылке `http://127.0.0.1:8080/#token=...`. Скрипт сразу считает токен из `#fragment`, удалит его из адресной строки (`history.replaceState`) и установит защищенную `HttpOnly` сессию.

## 🌐 Как соединиться через интернет (между сложными сетями)

### Вариант А: Через автопоиск в одной сети (LAN / Wi-Fi / Radmin / ZeroTier)
- Просто запустите `zvonochek.exe` на обоих ПК — через 2 секунды второй компьютер появится в блоке **«Узлы в локальной сети (mDNS)»**. Нажмите кнопку **«Подключить»**.

### Вариант Б: Через интернет по коду приглашения `zv2://`
1. Если оба компьютера находятся за сложным NAT (например, разные провайдеры без белого IP), запустите `zvonochek-relay` на любом сервере с белым IP:
   ```bash
   ./zvonochek-relay -port 4002
   ```
   Сервер выведет строку подключения вида `/ip4/X.X.X.X/udp/4002/quic-v1/p2p/12D3Koo...`.
2. Запустите клиент с указанием ретранслятора:
   ```cmd
   zvonochek.exe -relay "/ip4/X.X.X.X/udp/4002/quic-v1/p2p/12D3Koo..."
   ```
3. Скопируйте код **`zv2://...`** в карточке «Мое приглашение» и отправьте собеседнику.
4. Собеседник вставляет код `zv2://...` и нажимает **«⚡ Войти»**.
5. При нажатии **«📞 Позвонить»** программа сначала попробует прямое P2P-соединение WebRTC, а если UDP заблокирован — автоматически пустит голос через **Go libp2p Audio Bridge** поверх ретранслятора (либо вы можете выбрать этот режим сразу в выпадающем списке).

## 📦 Отправка в GitHub одним кликом

В архив добавлен скрипт `sync_github.bat`:
1. Запустите `sync_github.bat`.
2. Введите ваш логин GitHub, имя репозитория и ваш **новый** токен (старый токен из чата обязательно отзовите!).
3. Скрипт сам выполнит `git init`, `git commit`, отправит код на GitHub и сразу очистит токен из локального `.git/config`.
