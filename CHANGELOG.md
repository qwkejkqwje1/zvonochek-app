# Изменения

## 4.0.0 — первая версия приложения на Rust

- Новое приложение для Windows (x64 и ARM64) вместо 3.x: ядро на Rust, окна WebView2 (Tauri 2), новая иконка.
- Звонки по ссылке с веб-версией ZVONochek (v41, https://zvonochek.github.io/; ссылки со старого адреса тоже открываются) и между приложениями: окно звонка — встроенный веб-клиент,
  сигнализация — в ядре (MQTT WSS/TCP, Worker WS/HTTP, Nostr, ntfy).
- «Мои ссылки»: приложение ждёт звонков в трее, окно входящего с мелодией, «Не беспокоить», история звонков,
  уведомления о пропущенных.
- Быстрый набор, сохранённые ссылки, QR-код ссылки.
- Автозапуск, один экземпляр, ссылки `zvonochek://`, автообновление, диагностика каналов и проверка сети звонков
  (внешний адрес STUN и ретранслятор TURN из окна приложения).
- Данные хранятся локально, секреты зашифрованы.
- Windows — только переносная версия (`ZVONochek_<версия>_x64.exe` / `_arm64.exe`, без установщика): все данные — в
  папке `ZVONochek-data` рядом с exe (профиль WebView2, журналы, размер окна, полученные файлы и обновления — тоже),
  первый запуск копирует данные установленной версии из AppData; переключатель «Уведомления Windows» с проверкой,
  «Убрать следы с этого компьютера», удаление старой копии в AppData. Нельзя писать рядом с exe — понятное сообщение
  вместо тихого ухода в AppData; нет WebView2 — ссылка на загрузку.
- Самообновление: проверка релизов раз в 6 часов, загрузка нового exe с проверкой подписи Ed25519, замена exe на
  месте, «Перезапустить» в настройках; переключатель «Обновлять автоматически».
- Пароль профиля: ключ устройства, контакты и ссылки зашифрованы ключом данных; без пароля он запомнен только на этом
  компьютере (DPAPI), с паролем папку можно открыть на другом (окно пароля при запуске, «Запомнить на этом
  компьютере»). Папка с другого компьютера без пароля не открывается — понятное сообщение вместо пустого профиля.
- Контакты: приглашение кодом (QR), добавление по коду, «в сети», код безопасности, переименование, удаление;
  звонок и видеозвонок контакту без ссылок, ответ «без видео», отклонение и «Не беспокоить» видны звонящему.
- Прямые соединения между приложениями (P2P, iroh): звонок по ссылке между двумя приложениями сам переходит на P2P,
  голос моста — датаграммами; «Добавить в контакты» из истории; диагностика P2P.
- Чаты с контактами: сообщения онлайн и офлайн (почтовый ящик: доходит, даже если вы уже вышли), «доставлено» и
  «прочитано» (можно выключить), «печатает…», ответ, правка (↑), удаление у себя и у всех, поиск по чатам,
  черновики, ссылки и эмодзи, разделители дней и «Непрочитанные».
- Файлы и фото в чатах: скрепка, перетаскивание, вставка картинки; прямая передача с проверкой и докачкой после обрыва,
  превью картинок, «Открыть» и «Показать в папке», предупреждение об опасных файлах; папка `Загрузки\ZVONochek`.
- Уведомления о сообщениях, мигание окна и значок непрочитанных на панели задач и в трее.
- Перенос профиля на другой компьютер: файл под паролем (ID устройства, контакты, ссылки, история и переписка).
- Группы до 6 человек: переписка, файлы и групповые звонки (аудио и видео) с контактами; участники не обязаны быть
  контактами друг друга. Сообщения доходят и офлайн (ящик группы), подписаны ключом устройства автора; «доставлено
  всем», «печатает…» с именами, служебные строки, «Присоединиться» к идущему звонку из ленты. Администратор
  переименовывает, добавляет и исключает (с новым ключом группы); выйти и удалить группу у себя может каждый.
- Android 7.0+ (arm64 и armv7): то же приложение — контакты, чаты, файлы, группы и звонки; ожидание звонков в фоне
  (служба с уведомлением, без сервисов Google), полноэкранный входящий поверх экрана блокировки с кнопками «Ответить»
  и «Отклонить», экономный режим ожидания; APK — на странице релизов.
