# Изменения

## [3.0.0] — 2026-11-02

Полная переработка: новое P2P-ядро, протокол, хранилище, локальный API и интерфейс. Проект собирается одной командой,
покрыт тестами и выпускается через GitHub Actions.

### Главное
- Проект снова собирается (`go build ./...`) на Windows, Linux и macOS; `zvonochek.exe` — один файл без консоли,
  с иконкой, сведениями о версии и манифестом (DPI, длинные пути).
- Отдельное окно приложения (Edge/Chrome в режиме приложения), значок в трее, автозапуск с Windows,
  уведомления, один экземпляр на профиль, несколько профилей (`-profile`).
- Новые коды приглашения `zv3:` — компактные, с контрольной суммой, сроком действия и актуальными адресами.

### Безопасность
- Узлы из локальной сети больше **не становятся доверенными автоматически**: сообщения, звонки и файлы — только
  от подтверждённых контактов; незнакомцы могут лишь отправить запрос (с ограничением частоты); блокировка.
- Код безопасности для сверки собеседника.
- Локальный интерфейс: только `127.0.0.1`, одноразовый токен входа → cookie `HttpOnly; SameSite=Strict`,
  проверка `Host` (DNS rebinding), `Origin` и CSRF-заголовка, CSP и защитные заголовки, лимиты размера запросов.
- Удалён `sync_github.bat` с токеном GitHub в URL.
- Все кадры протокола ограничены по размеру и частоте; длинный текст и имена обрезаются.
- Принятые файлы получают «метку из интернета» (SmartScreen предупредит при запуске exe).

### Надёжность
- Новый протокол передачи файлов: подтверждение, потоковая запись в `.part`, проверка SHA-256, атомарное
  переименование, без перезаписи существующих файлов, очистка имён; отмена и отклонение с обеих сторон.
  Исправлена порча данных из 2.x.
- Офлайн-очередь сообщений с повторной доставкой и статусами «отправлено / доставлено / прочитано».
- Хранилище с атомарной записью; повреждённые `settings.json`, `contacts.json` или история больше не мешают запуску
  (файл сохраняется как `*.broken-<время>`).
- Автоматическое переподключение к контактам, повторная попытка занять порт, журнал с ротацией, `crash.log`.
- Перенос ключа личности из 2.x — ID не меняется.

### Связь
- Поиск собеседника параллельно: адреса из приглашения, mDNS, DHT, hole punching, UPnP, публичные и свои relay.
- Маяк для VirtualBox переписан: гостевая ОС сама находит хост через `10.0.2.2` / `192.168.56.1`, без ручных адресов.
- Свой relay-сервер `zvonochek-relay` без ограничений публичных relay (2 мин / 128 КБ), со списком допуска `-allow`.
- Звонки WebRTC (аудио, видео, демонстрация экрана) с автоматическим переходом на **аудиомост** через соединение
  Звоночка (Opus), если прямое соединение не установилось или оборвалось. Свой TURN-сервер в настройках.
- Во время звонка передача файлов притормаживается, чтобы не мешать голосу.

### Интерфейс
- Новый дизайн: тёмная и светлая темы, адаптивная вёрстка (вплоть до узкого окна), список «Рядом», запросы контактов,
  карточка контакта, журнал звонков, «печатает…», предпросмотр картинок, перетаскивание файлов.
- Окно звонка: сворачивание в панель, статистика соединения, выбор устройств, шумоподавление.
- Настройки по разделам: профиль, звук и видео (проверка микрофона и камеры), сеть с диагностикой, файлы,
  приватность, приложение.

### Разработка
- Тесты: хранилище, протокол, приглашения, интеграционные тесты двух узлов (контакты, чат, офлайн-очередь,
  файлы, звонки, блокировка), безопасность локального API. Все проходят с `-race`.
- `build_windows.bat`, `build.sh`, CI на Linux и Windows, релиз по тегу `v*` с контрольными суммами.

### Несовместимость
- Сетевой протокол 3.x несовместим с 2.x — обновите программу у всех собеседников.
- Коды `zv2://` больше не поддерживаются — обменяйтесь новыми кодами `zv3:`.
