# ADR-0009. Чаты сайта (`#chat=`) в приложении

Статус: принято · 4 ноября 2026 · дополняет ADR-0001

## Контекст
У сайта есть отдельные приватные чаты по ссылке `#chat=<seed>` (chat.js веб-клиента, ~6,6 тыс. строк): комната
ChatRoom в Worker (WebSocket `/chat/<id>/listen` + HTTP), резервный канал MQTT + Nostr + ntfy, файлы и голосовые,
PIN-комнаты. Приложение такие ссылки открывало в браузере. Переписывать чат на Rust — долго и дублирует код сайта.

## Решение
- **Окно «Чаты сайта» = встроенный веб-клиент** (тот же ui/web, что и окно звонка, ADR-0001), раздел «Чаты».
  ПК — отдельное окно `webchat` (одно на все чаты; новая ссылка меняет `location.hash`), Android — в главном окне,
  «Назад» из списка — в оболочку. Вкладки веб-клиента «Звонки» и «Мой номер» в этом окне скрыты.
- **Открытие:** ссылка `#chat=` в «Звонок по ссылке» → «Открыть»; кнопка «Чаты сайта» на странице «Чаты».
  Хост принимает только фрагмент `chat=<base64url>[&p=1]` (`zv_proto::link::chat_hash`).
- **WebSocket к Worker — через ядро.** Worker пускает только сайт и запросы без Origin, а у сокета WebView Origin
  (`https://tauri.localhost`) не убрать. preload.js подменяет `WebSocket` для `wss://*.workers.dev`:
  `ws_open {id, url}` → события `ws:open` / `ws:msg` / `ws:close`, `ws_send`, `ws_close`. Номер сокета —
  случайный, его выбирает страница (события идут во все окна). Страница раз в 30 с подтверждает свои сокеты
  (`ws_keep`), неподтверждённый дольше 3 мин ядро закрывает (окно закрыли, не успев закрыть сокет). HTTP к Worker
  уже шёл через ядро (`http_fetch`).
- **Service worker** в приложении выключен, поэтому `navigator.serviceWorker.ready` отклоняется сразу — иначе
  чат ждал бы его вечно (подписка на push при входе в комнату).

## Последствия
- Переписка, файлы, голосовые, PIN, резервный канал — как на сайте, код один; чаты хранятся в профиле WebView
  приложения (отдельно от браузера).
- Нет push: о новых сообщениях — только пока окно «Чаты сайта» открыто (системных уведомлений нет).
- Чат сайта не становится контактом: чаты контактов (P2P, ящики) — отдельная страница «Чаты».
